Nossa história

Uma loja de keys digitais feita para jogadores

A SteamKey Hub é um projeto Django voltado para venda de keys de jogos para Steam. A proposta é reunir um catálogo simples, com controle de estoque, compra para usuários logados e histórico de pedidos no perfil.

O sistema foi desenvolvido como trabalho de Web3, mantendo páginas institucionais, cadastro, login, produtos, contato e painel administrativo.
